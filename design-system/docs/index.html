System

A typographic system for olegchursin.com, built on the International Typographic Style: a visible grid, one grotesk in many widths, paper, ink and a single red.

Principles

  1. The grid is the design

    Twelve columns, one gutter, one margin. Everything snaps to a column edge. Asymmetry comes from how many columns a thing takes, never from nudging it.

  2. Type does the work

    One family, Archivo, used across its width axis: condensed and black for display, normal for reading, wide for small labels. Hierarchy comes from size and weight before colour.

  3. Red is rare

    Paper and ink carry the page. Red marks one thing per view: the current page, a block, a dot, a focus ring.

  4. Objective images

    Photographs appear in grayscale, square-cut, unframed. Colour returns when you ask for it by hovering or focusing.

  5. Flush left, ragged right

    Text aligns to the left edge of its column. No centred paragraphs, no justified text, lines under 64 characters.

Colour

Values switch with the theme. Red at text sizes uses --oc-red-text, which meets WCAG AA on paper and ink; --oc-red is for blocks, shapes and display type only.

Prose

Long-form text sits in <oc-prose>, in the light DOM, so it stays plain HTML. Paragraphs are set at 17px with generous leading and a 64-character measure.

Second-level heading

Headings are bold rather than big, introduced by a two-pixel rule.
